        See what a codebase does before you read it

        Open a repository and Terrarium draws it as C4 diagrams: who uses it, what runs, what each part is for, and how a request travels through. Every arrow is backed by the code, and Claude agents write the words.

          Discover with Claude

          A surveyor reads the manifests and entry points, one agent per container groups its code into components, one narrator per journey writes its sequence diagram, and an editor writes the guide. The engine checks every arrow. This spends money.

          Journeys to narrate

          Tick the flows you care about, name them by what the user is doing, and leave a note for the narrator. Leave everything unticked to let the surveyor choose.
